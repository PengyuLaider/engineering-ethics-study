## 第一章 概论

原书第 1–50 页。章末小结 46 页，案例分析 47 页，复习思考题 49–50 页。

| 节与起页 | 教材要点 |
|---|---|
| 1.1 工程和工程师，1 页 | 工程要结合理念、思维、哲学、管理、文化和教育理解。辨析科学的发现、工程的创造和艺术的想象。表 1-1 在第 7 页。工程师的职业关系涉及工人、雇主和社会，见第 11–16 页。 |
| 1.2 工程过程中的伦理问题，17 页 | 当代工程的高科技、大规模集成和社会化带来伦理问题。工程从行为、规范、观念三层影响道德。表 1-2 在第 21 页，列出从概念设计到产品拆解的典型伦理问题。工程决策的价值权衡见紧接表后的正文。 |
| 1.3 伦理学及工程伦理学的含义，25 页 | 工程伦理学研究怎样理解指导工程实践的道德价值、化解工程道德问题并论证判断。研究跨学科、多层次，属于实践伦理。关注实际后果与行为所负义务，见第 28–31 页。 |
| 1.4 研究工程伦理学的意义及方法，32 页 | 规范性研究问应当如何及其理由，概念性研究澄清概念或原则，事实性研究提供判断所需证据。区分研究问题的类型，并在实际案例中配合使用。见第 35–37 页。 |
| 1.5 工程伦理准则与工程师的职业伦理，38 页 | 本节逐条论述的五项准则是以人为本、关爱生命、安全可靠、关爱自然、公平正义，见第 41–42 页。职业伦理还涉及质量与安全、诚信、正直、公正、工程师与管理者，见第 42–45 页。 |

## 第二章 伦理学与工程伦理学研究综述

原书第 51–71 页。章末小结与案例分析 69 页，复习思考题 71 页。

| 节与起页 | 教材要点 |
|---|---|
| 2.1 伦理学研究综述，51 页 | 教材以反思性启蒙、世俗化、社会化概括改革开放以来中国伦理学理论的演进。讨论义利、公平正义、效率以及如何形成伦理秩序。三个阶段见第 53–55 页。 |
| 2.2 工程伦理学研究综述，60 页 | 从现实问题进入学科建设。教材列举责任、公平、安全、风险四项规范，以复杂性和特殊性概括学科特征。狭义关注工程师职业伦理，广义延伸到工程决策、政策和项目实践全过程。见第 63–69 页。 |

## 第三章 工程师的责任

原书第 72–102 页。章末小结与案例分析 101 页，复习思考题 102 页。

| 节与起页 | 教材要点 |
|---|---|
| 3.1 工程观及其演变，72 页 | 工程系统观、社会观、生态观、伦理观、文化观是理解工程理念的维度。教材将理念演变概括为听天由命、征服自然、天人和谐。见第 73–75 页。 |
| 3.2 工程责任观的演变，76 页 | 比较三个历史强调点，公司忠诚、技术专家领导、社会责任。现代工程师同时对雇主、最终消费者和更广公众承担责任。见第 77–80 页。 |
| 3.3 工程技术发展与责任的关系，81 页 | 比较技术目的、可预见影响和技术使用导致的后果。随着工程影响范围扩大，工程师需要识别技术的负面效应并相应尽责。见第 81–84 页。 |
| 3.4 工程师的职业道德，85 页 | 职业判断包括技术、经济及伦理维度。个人道德发展按前专业人员、专业人员、有原则的专业人员三个层次理解，同时分析不同职业准则的冲突。见第 85–89 页。 |
| 3.5 工程师责任的种类，90 页 | 产品设计质量、制造监督、被动与主动责任、国际环境中的超文化规范和社会责任。被动与主动的对比见第 93–95 页。知情同意的两项条件见第 95 页。 |

## 第四章 工程中的利益相关者与社会责任

原书第 103–130 页。章末小结与案例分析 128 页，复习思考题 129–130 页。

| 节与起页 | 教材要点 |
|---|---|
| 4.1 契约理论，103 页 | 经济学意义的契约涵盖权利关系、协议、默认和承诺。古典、新古典、现代契约理论三阶段。订立原则是平等性、自由性、守信、互利性。见第 105–107 页。 |
| 4.2 利益相关者理论，107 页 | 企业伦理、社会责任和环境管理说明理论背景。企业可以理解为所有利益相关者之间的一组多边契约，涉及管理者、员工、所有者、供应商、客户、社区等。见第 109–110 页。 |
| 4.3 工程及其利益相关者，111 页 | 由工程的社会性识别投资、组织、设计、实施、使用及受影响者。分析工程共同体中的工程师、工人及其他主体，尤其是议价和知情能力较弱的群体。见第 113–121 页。 |
| 4.4 工程建设与社会责任，121 页 | 比较服从命令、忠诚、普遍责任、社会责任及自然与生态责任的演变，联系工程的社会影响和选择时拥有的权力。见第 122–128 页。 |

## 第五章 工程中的诚信与道德问题

原书第 131–158 页。章末小结与案例分析 157 页，复习思考题 158 页。

| 节与起页 | 教材要点 |
|---|---|
| 5.1 工程中的人道主义，131 页 | 用安全、尊重、公正、社会福利、合理补偿分析工程对人的影响。社会福利的例外理由须谨慎使用。见第 132–137 页，五项要求见第 136 页。 |
| 5.2 工程领域的诚信规则，137 页 | 不说假话、不故意隐瞒事实真相、最大程度公开信息、对相关信息说明解释。真实、完整、及时、可理解各有具体要求。见第 139 页。 |
| 5.3 工程研究中的诚信、道德和正直，140 页 | 对实验与研究结果诚信，尊重他人智力成果，尊重知情权，遵守人道主义，妥善对待雇主权益。用黄禹锡事件区分数据、署名或利益问题。见第 141–144 页。 |
| 5.4 工程制造与建造中的诚信与道德，144 页 | 依法制造或建造，践行诚信、人道主义与勤勉忠实。把准则落到材料、工序、检验、质量记录和缺陷处置。见第 145–146 页。 |
| 5.5 工程试验中的诚信与道德，146 页 | 关注改数据、未检先出报告、超范围出报告、偷减检测。答题应把诚信正直、勤勉、人道主义和忠实联系到完整记录和如实报告。这里的忠实指忠于检测事业。见第 147–148 页。 |
| 5.6 与商业有关的工程诚信与道德，149 页 | 商业活动中比较诚信、人道主义、公平及忠实勤勉义务。用保密、公平交易、设计与知识产权的利益冲突作应用。见第 149–151 页。 |
| 5.7 工程师在公共事务中承担社会角色时的诚信与道德，151 页 | 专家以证据出具意见，受人道主义、诚信和公平正义约束，并考虑专业不确定性与社会责任。案例见第 151、155 页，准则见第 153–157 页。 |

## 复习时常见的口径差异

- 第 1 章第 41–42 页逐条展开以人为本、关爱生命、安全可靠、关爱自然、公平正义五项准则。第 41 页同节和第 2 章第 69 页另以责任、公平、安全、风险概括道德规范。第 5 章第 136 页的人道主义要求是安全、尊重、公正、社会福利、合理补偿。按题干所问概念和枚举范围作答。
- 责任观三个历史阶段、工程理念三个历史时代、职业道德发展三个层次分别对应第 77–80 页、第 73–75 页和第 86–87 页。
- 合同承诺、商业保密和组织忠诚需要结合公众风险、证据和实际权责分析。第 3 章强调主动预防，第 5 章强调诚信，第 6 章给出冲突权衡方法。
- 教材按单栏正文组织，学习目标、案例、章末小结、思考题和二维码分工明确。目录和页索引可用来限制命题范围，各章小结适合归纳，原页用于确认术语、编号、图表和事实。
