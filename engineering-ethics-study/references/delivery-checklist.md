# 案例分享交付检查

## 案例与论证

- [ ] 让受众在开场了解地点、参与者、任务和正常安排。尽早进入影响后果的关键决定和工程动作。
- [ ] 核对数字、单位、时间、人物、图像与来源定位。计划、执行、影响和不确定性准确传达。
- [ ] 至少完成一条由评价标准和案例事实支持的伦理判断，说明岗位条件、控制能力和组织责任。
- [ ] 讲清历史整改和后续建议。给出执行岗位、验收证据和复核时机。

## 讲述与图解

- [ ] 口播首次说明技术缩写，准确表达已有证据的限制，页与页有衔接。口播、媒体和过渡符合约定时长。
- [ ] 图源靠近图片，标明原始资料或教学示意。时间轴和连接线有清晰含义，对照图保持同一对象和单位。
- [ ] 逐页检查渲染画面和投影可读性。按要求验证可编辑性、文件打开和媒体放映，并说明实际验证的范围。

## 整套材料

- [ ] 核对封面、母版、页眉页脚、结束页、隐藏页和备注。保留用户确认的模板、署名和口语改稿。
- [ ] 增删或移动页面后，复核导航、交叉引用、页码、图注、参考链接和讲稿页序。
- [ ] 检查片段首尾、字幕和声音，确认正式调查后有更正的内容已正确表述。供分享的文件按用户要求选取。
